# PizzeríaBD 🍕  
***Autor: Fernando Cordero***

En este proyecto se llevo a cabo el diseño y gestión de una base de datos de para una pizzería, incluyendo elementos como pedidos, empleados, pizzas y más.

## 📖 Descripción  
Este repositorio contiene la estructura y funcionalidades necesarias para administrar una pizzería mediante una base de datos. Aquí podrás encontrar herramientas para:  
- Registrar y gestionar pedidos.  
- Controlar los menús y sus precios.  
- Gestionar entregas a domicilios.
- Registrar pagos. 

## ⚙️ Tecnologías Utilizadas  
Este proyecto utiliza las siguientes tecnologías:  
- **Base de datos**: MySQL.
